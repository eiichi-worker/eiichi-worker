# RESUME_HTML/CLAUDE.md

藤本の職務経歴書を、HTMLとA4のPDFで出力するためのフォルダーです。内容はすべて`resume.jsonc`に書き、ほかのファイルは表示の仕組みだけを持ちます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `resume.jsonc` | 職務経歴書の内容（JSONC：コメントと末尾のカンマが使えます） |
| `index.html` | ページの枠。`app.js`と`style.css`を読み込むだけ |
| `app.js` | `resume.jsonc`を読み込んで描画する。値はすべてtextContentで入れる |
| `style.css` | 画面表示とA4印刷の見た目 |
| `make-pdf.ps1` | Edgeのヘッドレス印刷でPDFを作る |

## 確認とPDFの作り方

- PDF：リポジトリのルートで`mise run pdf`を実行すると、次の2つを`.local/`（Git管理外）に作ります。1つだけ作るときは`-Variant full`か`-Variant masked`を付けます。
  - 通常版：`職務経歴書_藤本永一_YYYYMMDD.pdf`
  - 匿名版：`職務経歴書_FJME_YYYYMMDD.pdf`。氏名・会社名・付録のURLを伏せたものです。
- 画面：`python -m http.server -d RESUME_HTML`などでローカルサーバーを立てて開きます。`index.html`を直接開くと、ブラウザの制限で`resume.jsonc`を読み込めません。
- 内容や見た目を変えたら、PDFを作り直し、変えたページを画像にして目で確認します。確認用のスクリプトや画像は`.local_claude/preview/`に置きます（`render.py`、`crop.py`、`check-data.mjs`、`check-tags.mjs`、`test-jsonc.mjs`）。
- 匿名版は、URLに`?masked`を付けて開くと画面でも確認できます。伏せる内容は`resume.jsonc`の`masked`に書きます（`replace`はすべての文字列に上から順に適用、`hide`は表示しない項目、`set`は値を差し替える項目、`ageRange`は年齢を「30代後半」のような年代で表示）。PDFのファイル名は、描画後のページタイトルから決まります。
- `make-pdf.ps1`は、匿名版に置き換え前の文字列や伏せた項目の値が残っているときも、PDFを作らずにエラーで止まります。
- `make-pdf.ps1`は、描画に失敗したとき（`<html data-state="error">`）や`resume.jsonc`の書き間違いがあるときは、PDFを作らずにエラーで止まります。

## resume.jsoncの決まり

- 同じ種類のオブジェクトは、すべて同じプロパティを持たせます。値がないものは`null`にします（空文字や`[]`は使いません）。
- 期間：`{ "from": "2024年02月", "to": "現在" }`の形にします。月は2桁です。サブプロジェクトの`period`も同じ形で、文字列にはしません。
- スキルの`since` / `until`：`"2024-02"`の形です。`until`があるタグは「いまは使っていない技術」として破線の枠で表示します。
- 案件は会社ごとに、開始の新しい順に並べます。
- 強みの`evidence`と主な実績の`ref`には、職務経歴の案件名（`title`）をそのまま書きます。案件名を変えたら、こちらもそろえます。
- 推しと嫌い：スキル欄のタグの`featured`は、`true`が推し、`null`が特になし、`false`が嫌い（うっすら水色）です。推しは「推しの技術」に集計されます。職務経歴のタグは、括弧書きを除いた名前（`AWS（Lambda）` → `AWS`）で照合し、一致すれば色が付きます。名前が一致しないと色が付かないので、スキル欄と職務経歴のタグ名はそろえます。
- 注釈：本文に`※1`と書くと、上付きの注釈番号（`notes`へのリンク）になります。`notes`は並び順に ※1、※2… と番号が付くので、文章には「※」を書きません。番号は本文で最初に出てくる順に振ります。

## 表記の決まり

- 文章は丁寧語で書き、ルートの`.claude/CLAUDE.md`のとおり`yomiyasu`スキルで整えます。職務経歴の表の中（課題・取り組み・成果）は、常体・体言止めのままにします。
- 「改善」は「カイゼン」と表記します。
- HRTの訳は、藤本の解釈で「謙虚・敬意・信頼」です（注釈では「私の解釈」と書きます）。一般的な訳（謙虚・尊敬・信頼）との違いは注釈で説明しているので、一般訳には直しません。
- 「問題 vs 私たち」は考え方の名前です（`resume.jsonc`と同じ表記）。誤記ではありません。
- AWSの製品は正式名で書きます（「AWS Lambda」「Amazon S3」「Amazon RDS」「AWS App Runner」「Elastic Load Balancing」など）。

## これまでにハマった点

- **印刷時にスマホ向けの表示になる**：A4の印刷幅は約700pxです。狭い画面向けの指定は`@media screen and (max-width: 760px)`のように`screen`に限定します。
- **`replaceChildren()`に`null`を渡すと「null」と表示される**：表示しないセクションは、`filter(Boolean)`で取り除いてから渡します（`el()`の子要素は`null`を飛ばすので問題ありません）。
- **Edgeの終了を待たずに後片付けすると、古いPDFが残る**：`make-pdf.ps1`では`Start-Process -Wait`でEdgeの終了を待ち、毎回新しいプロファイルで起動しています。`-Out`は絶対パスに変換してから渡します。
- **改ページ**：案件、カード、主な実績、注釈、推しの技術の欄には`break-inside: avoid`を付けています。1ページに収まらない長さの案件だけは、見出しから技術タグまで（`.project-main`）とサブプロジェクトの単位で切れます。ページ数は気にせず、読みやすさを優先します（タグが1つだけ次のページにはみ出すような切れ方は避けます）。
- **PowerShellの変数名**：大文字と小文字を区別しないので、`$Zoom`と`$zoom`は同じ変数として扱われます。
- **フォントが図形（Type3）としてPDFに入る**：EdgeのPDF出力は、可変フォントとCFF形式（`.otf`）のフォントを図形として埋め込みます。このとき、PDFからのコピーや検索が崩れます。そのため`make-pdf.ps1`が、Google Fontsの可変フォントから標準と太字のTrueTypeを切り出して`fonts/`（Git管理外）に置きます。
- **「一」が「⼀」としてコピーされる**：Noto Sans JPは、部首の文字（U+2F00〜）と漢字が同じ字形を共有しています。切り出すときに、部首と互換漢字を文字の対応表から外しています。
